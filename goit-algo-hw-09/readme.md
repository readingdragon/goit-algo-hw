Жадібний алгоритм та алгоритм динамічного програмування відрізняються за ефективністю залежно від умов:

### Жадібний алгоритм
- **Часова складність**: O(n), де n — кількість номіналів.
- **Швидкий** проте **Не завжди оптимальний**  може не знаходити мінімальну кількість монет для кожного випадку.

### Алгоритм динамічного програмування
- **Часова складність**: O(m * n), де m — сума, а n — кількість номіналів.
- Завжди знаходить **оптимальне рішення** 
- **Повільніший на великих сумах** через складніші обчислення, але гарантує мінімальну кількість монет.

### Висновок
- Жадібний алгоритм підходить для канонічних наборів і великих сум.
- Динамічне програмування ефективніше для неканонічних наборів, забеспечує оптимальне рішення, хоча й повільніше для великих значень.
