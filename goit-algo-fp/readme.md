## Висновки
 Метод Монте-Карло дозволяє визначати ймовірності сум чисел, що з'являються при киданні двох кубиків, за допомогою випадкових вибірок для визначення частот.

### Переваги методу Монте-Карло:
1. **Легкість у реалізації**: Програмування для моделювання випадкових подій є досить простим.
2. **Універсальність**: Метод можна застосовувати до широкого спектру задач і систем.
3. **Можливість оцінки похибок**: Метод Монте-Карло дозволяє оцінити похибку обчислень на основі статистичного аналізу результатів. Чим більше ітерацій, тим точнішою стає оцінка.
4. **Здатність працювати зі складними моделями**: Метод Монте-Карло добре підходить для задач, де традиційні аналітичні методи є непридатними або складними.

### Недоліки методу Монте-Карло:
1. **Тривалість обчислень**: Для досягнення точності потрібно багато симуляцій, що може зайняти значний час.
2. **Випадкові коливання**: Результати можуть мати випадкові флуктуації, які потребують додаткових симуляцій для їх усереднення.
3. **Нестабільність при малих вибірках**: При недостатній кількості симуляцій результати можуть бути неточними і навіть нестабільними, що може призвести до хибних висновків. Метод потребує великої кількості ітерацій, щоб дати стабільний результат.
